Service Sheet Electronic

让现场与远程技术服务记录进入同一套电子化流程

项目覆盖工程师填写、客户签名、管理端查询、固定版式导出、客户分享和个人月报统计，减少纸质服务表流转和重复整理。

Core Workflow

核心能力

工程师端服务记录

支持现场服务和远程服务两类记录，按场景展示不同字段，并提供客户信息、联系人、设备和处理记录填写。

客户签名与分享

现场服务可采集客户手写签名，生成固定版式技术服务咨询表，并用于客户留底分享。

月报统计导出

服务记录自动进入个人月报，工作性质和类别使用中文描述，也支持补充学习研究、内部会议、文档整理、培训等月报条目。

管理端协同

管理端可查看服务单、客户、设备和月报信息，并使用与工程师端一致的服务表导出格式。

Technology

技术栈

前端

Vue 3、Vue Router、Pinia、Vite，以及基于 CSS 变量的多主题界面。

后端

Node.js、Express、MySQL 8、mysql2 和 JWT 鉴权，承载服务记录、客户资料和月报 API。

导出

ExcelJS、xlsx、html-to-image，以及固定版式 SVG/PNG 技术服务咨询表。

部署

Docker、Docker Compose、Caddy、GitHub 私有仓库和 GitHub Pages 公开展示页。

Release Notes

近期更新

工程师端

服务表补充外勤行程时间

正式工程师端的新建/修改服务表将“出发时间”“返抵时间”收进可选区块，适合加班或外勤返程记录；导出时未填写就不显示空列，填写后才随服务表保留。

正式入口

工程师登录页可切换版本

正式和预览入口统一显示为“正式版 / Preview1（仅视觉预览） / Preview2(仅视觉预览)”，并仅保留在登录页；进入预览业务页后不再显示悬浮版本切换。

Preview

客户快速带入可点选历史记录

Preview1 和 Preview2 的新建服务表会展示本人最近最多 10 条历史服务记录，点击后可带入客户、联系人、设备和服务内容字段。

Preview1

工程师页补齐账号与语言操作

Preview1 工程师业务页右上角新增小型当前用户、简繁切换和退出按钮，导航当前态也改为精确高亮。

Preview2

第一套 v0-ui 已挂到正式域名子路径

新的 preview2 可通过管理端和工程师端正式域名的 /preview2 入口直接查看，用于和 preview1、正式 Vue 版本并行对比。

Preview1

Figma MCP preview 也进入正式域名子路径

Figma MCP 版本现在可通过 /preview1 查看，并和 preview2 一起提供顶部版本切换，测试时不用再记多组独立域名。

工程师端

月报页改成更适合桌面查看的总览布局

工程师端月报现在会把服务总数、工时、现场/远程占比、类型分布、周趋势和活动明细集中展示，方便在电脑上快速浏览整月工作情况，同时继续保留 Excel 导出。

协作流程

新增 preview 双轨发布文档和脚本

主仓库现已补充 preview 前端工作流说明和独立发布脚本，后续 v0 / figma 或外部 preview 前端可以单独发布到 preview 域名，不影响正式站点使用。

流程收口

派单和审核残留已从当前产品流里移除

正式前后端、工程师说明和 preview 设计源现已统一使用“新建、填写、提交、查询、导出”的服务记录流程，不再把派工、开始处理、审核和归档当作当前界面能力暴露，减少后续设计联动时的理解偏差。

测试发布

v0 工程师端个人页可保存真实签名

工程师 preview 新界面的个人页现在会读取正式账号资料，并可把手写签名直接保存到真实工程师账号，方便继续在新 UI 上验证个人签名维护流程。

测试发布

v0 工程师端可预览并分享真实服务表

工程师 preview 新界面的服务记录详情现在可直接进入分享预览，按正式服务单数据生成技术服务咨询表图片，并支持下载或调起系统分享，方便继续在新 UI 上验证客户留底流程。

测试发布

v0 工程师端月报开始读取真实月度数据

工程师 preview 新界面的月报页现在会按所选月份读取正式系统里的服务记录和内部工作明细，并按现场/远程服务做统计汇总，便于继续在新 UI 上验证月报体验。

测试发布

新 UI 可独立发到 preview 站点

现有正式前端继续保持生产环境稳定，新的 v0 / figma 设计前端可单独发布到管理端和工程师端 preview 域名，便于测试新界面与新流程，同时不影响正式站点使用。

弱网场景

工程师端先具备离线打开和本机草稿能力

工程师端现在可安装到手机或电脑桌面，第二次打开后即使现场网络不稳，也能继续进入已访问页面、查看缓存工单，并把服务表内容先保存在本机，避免填写到一半丢失。

工程师端

现场服务填写更顺手

工程师可以从已有服务记录进入填写，也可以主动新建服务表。新建时“客户名称”默认先显示本人最近 10 条历史服务记录，方便快速带入客户、联系人、地址和设备；需要找附近公司时，可点击右侧定位按钮继续搜索。

Figma MCP Preview

独立双端预览前端成型

新增由 Figma MCP 设计依据驱动的管理端和工程师端 preview，覆盖登录、工作台、服务记录、客户资料、月报、任务、详情、分享预览、个人页和移动端卡片布局；工程师端月报、密码修改和个人签名也已按正式接口补齐。

客户留底

签名、预览和分享流程完善

现场服务支持客户手写签名和历史签名复用，提交后可先预览固定版式服务表，再分享给客户留底，导出格式与管理端保持一致。

月报统计

服务记录和内部工作统一进入月报

现场服务、远程服务会自动进入个人月报，培训、会议、学习研究等内部工作可手动补充；导出的 Excel 带有 logo、边框、换行、链接和更完整的空白填充。

管理协同

角色权限和客户资料更清晰

管理端拆分工程主管和业务主管权限，左侧菜单按登录角色即时更新；客户多联系人维护、同名联系人合并和服务记录查询导出也持续完善。
